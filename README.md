# Social-Media-Engagement-Analytics

# 📌 Project Overview
This project analyzes social media engagement data (likes, comments, shares, impressions, watch time, followers) to uncover trends, user behavior, and content performance.
It demonstrates data cleaning, transformation, exploratory data analysis (EDA), statistical analysis, and visualization using Python libraries.

# 🛠️ Tech Stack
-- Python (3.8+)

-- Libraries: Pandas, NumPy, Matplotlib, Seaborn, Plotly

-- Environment: Jupyter Notebook / Google Colab

#  📂 Dataset
File: social_media_engagement_5000.csv

Contains 5,000 rows of engagement metrics across different post types, countries, and user demographics.

# 🚀 Project Workflow
## 1. Data Import & Setup

* Load CSV with Pandas

* Convert date columns to datetime
  
## 2. Data Cleaning

* Handle missing values (fillna, dropna)

* Remove duplicates

* Standardize categories (gender, sentiment)

* Correct unrealistic values

* Extract hashtag counts

## 3. Exploratory Data Analysis (EDA)

* Dataset structure (head, info, describe)

* Categorical distributions (value_counts)

* Correlation matrix

* Groupby summaries

## 4. Data Wrangling

* Create new features (engagement_score, log_likes)

* Groupby by post type, country, sentiment

## 5. Statistical Analysis

* Mean, median, mode

* Variance, standard deviation

* Percentiles

## 6. Data Visualization

* Matplotlib: scatter, line, bar, pie, histogram, box plots

* Seaborn: count plot, heatmap, regression line

* Plotly: interactive line chart

## 7. Insights & Reporting

* Content performance

* User trends

* Behavioral insights

* Sentiment analysis

# 📊 Key Insights
✔ Video posts drive the highest engagement.

✔ Lifestyle & entertainment categories perform best.

✔ Evening posts (6–9 PM) yield maximum impressions.

✔ Positive sentiment posts generate more likes and shares.

✔ Verified accounts outperform non‑verified accounts.

# 📈 Visualizations
✔ Scatter plot: Likes vs Impressions

# Conclusion
This project successfully demonstrates how Python can be applied to clean, analyze, and visualize social media engagement data. By combining statistical analysis with clear visualizations, it uncovers actionable insights into content performance, user behavior, and sentiment trends. The findings highlight strategies such as focusing on video content, posting during peak hours, and leveraging positive sentiment to maximize engagement.
